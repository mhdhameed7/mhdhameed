# Mohammed Hameed - Personal Portfolio Website

Welcome to the repository for my personal developer portfolio! This website serves as a digital resume and a showcase of my projects, skills, and educational background. It is designed with a sleek, dark aesthetic and features smooth animations and a responsive layout to ensure a great user experience across all devices.

## 🚀 Features

- **Custom Preloader:** A cinematic, text-heavy preloader with a progress bar and smooth fade-out.
- **Dark Premium Theme:** A modern, dark aesthetic with subtle neon accents and glassmorphism elements.
- **Responsive Design:** Fully responsive layout that looks great on mobile, tablet, and desktop devices.
- **Interactive Animations:** Scroll-triggered reveal animations and a typing effect in the hero section.
- **Direct Contact Integration:** The contact form is seamlessly integrated with WhatsApp, allowing visitors to send messages directly without a backend server.
- **Project Showcase:** Detailed cards for my selected work, including mockups, technology tags, and direct links.

## 🛠️ Technologies Used

This portfolio is built entirely from scratch without the use of heavy front-end frameworks to ensure fast load times and clean, maintainable code:

- **HTML5:** Semantic markup for clear structure and accessibility.
- **CSS3:** Vanilla CSS with custom properties (variables), Flexbox, CSS Grid, and keyframe animations. (No Tailwind or external CSS libraries)
- **JavaScript (Vanilla):** Handles the preloader, scroll events, mobile menu toggling, intersection observers for scroll animations, and WhatsApp redirection logic.

## 📂 Project Structure

- `index.html`: The main HTML document containing the structure of the single-page application.
- `style.css`: All the styling rules, including responsive media queries and animations.
- `script.js`: Interactive logic, form handling, and DOM manipulation.
- `resource/`: Directory containing all assets (images, PDFs, SVGs) used throughout the site.

## 💻 Getting Started

To view this project locally on your machine:

1. Clone this repository or download the source code.
2. Ensure you have the `resource` folder in the same directory as the HTML file.
3. Open `index.html` in your favorite web browser (Chrome, Firefox, Safari, Edge).
4. No build steps, package managers (npm/yarn), or local servers are required!
